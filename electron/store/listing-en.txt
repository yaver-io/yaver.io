Description
Yaver is a self-hostable developer tool with publicly available source code. The Microsoft Store edition includes a native x64 Windows agent and the Yaver desktop client. Use this PC as a development node, control another authorized Yaver node, or do both together.

Start Codex, Claude Code, OpenCode, or terminal tasks against a repository on this PC or a paired node. Follow live output, approve work, and use Browser, Hermes, or WebRTC rendering lanes when the selected project and installed toolchains support them. Coding-agent output is live generative AI content when you select a generative AI runner. Report inappropriate output through the publisher support link on this listing.

Your source code remains on the machine running the task unless you choose a workflow that sends it elsewhere. The Store package does not bundle WSL, a Linux distribution, services, drivers, or third-party coding tools. Node.js, project SDKs, browsers, FFmpeg, and coding runners are installed or selected only for workflows that need them. The local agent runs only while the desktop app is open; the Store package creates no hidden startup task.

Yaver's core source is published under FSL-1.1-Apache-2.0 and each release converts to Apache-2.0 after two years; client SDKs are Apache-2.0 from release. The Store download is free. Optional third-party AI providers, managed workspaces, or relay services may require separate accounts or subscriptions.

System requirements
64-bit Windows 10 or Windows 11 and an x64 processor.
Internet access and a Yaver account are required.
Git, Node.js, project SDKs, browsers, FFmpeg, or coding-agent accounts are required only for workflows that use them.
WSL2 is not bundled or required for the native Windows agent. It may be installed separately for optional Unix-shell workflows.
